# 桌面视觉重排

依据用户最新反馈，目标是清爽、克制、清晰的信息层级，而非堆叠默认控件。保持无循环动效。

已改入开发分支：
- 全局浅色基础从蓝灰转为中性灰白，蓝色仅用于必要动作与状态；用户气泡为中性色。
- 统一深色底、圆角方形的首字头像组件，用于侧栏与个人资料主卡。
- 个人页主内容上限860dp、页边40dp，标题与账号操作同一行；删除重复的顶部信箱/工单按钮和资料卡内退出按钮。
- 资料主卡展示头像、昵称、邮箱和会员标签；账户概览横排会员/余额/曦光，日期为次级信息；信箱/工单为可点击并列卡片。
- 设置与我的导航统一图标、44px左右行高、白色选中项、轻量搜索；返回工作台使用中性色按钮。
