# Yxi Windows 1.4.0 使用说明

[下载1.4.0安装包](https://yxi.keuury.com/desktop/Yxi-win-Setup.exe?v=1.4.0)

## 开始工作

1. 从左侧添加并连接服务器。服务器配置保存在本机，掉线后重新连接即可。
2. 点击新对话，选择目录和运行器。使用Codex时，可选择“在对话工作台继续”；也可从账户菜单进入“Codex 任务”。
3. Yxi账户登录与服务器运行器登录分别管理。服务器需要安装对应运行器并完成其认证。
4. 已有Codex对话可通过“恢复任务”输入任务编号恢复；编号可在任务工具栏复制。

## 对话、队列和预览

- 输入要求后点击“加入队列”，或按Ctrl+Enter。默认手动发送，勾选“自动逐轮发送”后依次执行。
- 运行中可用下一条指令引导当前轮次，或请求中断。状态待确认的指令不会自动重发，请先查看任务历史。
- “项目文件”用于浏览服务器文件；文件链接可进入右侧预览。Markdown支持预览与源码编辑，保存遇到远端改动时会提示比较。
- “网页预览”用于查看项目页面、选择元素和提出修改要求。拖动分隔线可调整宽度，反馈先进入草稿。
- “Git 改动”显示项目差异，可打开文件或把差异引用到对话。
- 图片可选择或粘贴；普通文件上传后以服务器路径交给Agent读取。上传失败可重试或移除。

## 模型、线路和目标

- 模型选择用于之后发送的轮次；运行器最近报告的模型单独显示。
- 线路页会列出影响范围。需要重开的配置可使用“用当前服务器配置新建 Codex 任务”；原任务和草稿保留，新任务不自动继承旧对话。
- 目标条只显示服务器已有目标的状态和用量。当前未提供未经确认的持续执行控制。

## 任务整理与提醒

- 支持搜索、重命名、置顶、归档和单任务静音。设置中可选择只提醒置顶任务；没有任何置顶时提醒全部。
- 收藏启动入口保存主机、目录与运行器。原实例仍在线时打开原实例，已结束时预填新建表单，不自动恢复旧转录或协作组。
- 协作组的成员、组规和负责人通过既有服务器分组入口管理，本地收藏不会更改组规。
- 输入历史可以查看完成、失败和中断结果。可选3/7/30天清理已结束记录的正文，默认一直保留；未完成指令和去重标识保留，服务器对话不删除。

## 三种语音方式

| 方式 | 配置与使用 |
| --- | --- |
| 服务器识别 | 所选服务器安装yxi-asr；弹窗提供安装说明。录音经SSH发送到该服务器。 |
| Windows语音 | 选择该模式、聚焦编辑框，按Win+H听写；需要Windows在线语音服务和系统权限。结束前在系统面板停止听写。 |
| 本机离线 | 准备whisper.cpp程序与模型，填写程序和模型文件路径。Windows需whisper-cli.exe；Yxi不会自动下载模型或上传录音。 |

三种方式的文字都先进入可编辑草稿，由你确认加入对话。识别质量、麦克风兼容和本机模型需在实际设备上确认。

## 账户、钱包与商城

- “我的”可输入会员码或余额券。重复兑换与撤销结果会单独说明。
- 钱包显示余额、订单和兑换码，自动续费报价取自服务器。开启续费后，会员到期会按服务器规则从余额扣款。
- 商城购买的是兑换码，需要自行兑换。购买前会显示商品、期限和金额，并重新读取目录。
- 购买结果不明确时保留原请求编号。先查看订单，再选择核对/重试原请求，避免另起新请求。
- 客户端目录复核不等于服务端原子锁价；以服务器订单回执核对实际扣款。

## 交付边界

正式Windows构建和安装启动流程已通过。模拟协议检查不等于真实交易、麦克风、模型或所有UI场景的验收；剩余清单见[手动验证文档](windows-manual-verification.md)。

“三个月”权益规则与“Laize”具体名称/命令仍待确认，未自动赠送权益或添加猜测的运行器。已有Codex线程的提供方热切换仍未实现。
