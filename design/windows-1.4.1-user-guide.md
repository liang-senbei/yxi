# Yxi Windows 1.4.1 项目菜单使用说明

本说明对应正在构建的 1.4.1；正式发布状态见 [发布记录](windows-1.4.1-release.md)。

连接服务器后，左侧会按任务的工作目录显示项目。点击项目名称可展开或收起任务。

项目右侧的 **＋** 用于新建任务，目录已填好，可继续选择 Claude Code 或 Codex。需要时可在创建前调整目录或选择独立 Git worktree。

点击 **…** 可以查看完整目录、所属服务器、任务总数和运行中数量。路径支持选中和复制；任务总数包含当前服务器快照中的该目录任务，可能多于筛选后可见的数量。

选择 **编辑项目** 修改本机显示名称，保存后重启仍保留。留空保存可恢复目录名。修改名称不会移动服务器目录。侧栏搜索同时支持项目名称与原始路径。

选择 **协作组与组规…**，再选择对应的协作组，点击 **编辑成员与组规**。这里编辑的是服务器上的实际协作组。项目目录与协作组各自管理，名称相同也不会自动绑定。

新建任务以表单中的目录为准。已有任务的目录不能通过修改项目显示名称迁移。没有已有会话的目录不会仅因曾显示过就永久出现在项目树中；需要保留日常启动入口时，可在任务菜单中收藏。

其他功能沿用 [1.4.0 使用说明](windows-1.4.0-user-guide.md)。
