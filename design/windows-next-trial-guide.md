状态：候选包已生成，源码为 `accfaf5`，协议功能基线为 `4281b22`。Windows运行目录和未签名Setup位于父工作区 `artifacts/windows-accfaf5/package`，独立启动入口为 `Start-Yxi-Trial.cmd`。新版尚未由中枢启动或完成实机验证。旧试用包 `3152af0` 原样保留，本页新增功能不能作为旧包的使用说明。

## 从哪里开始

1. 在左侧选择已保存的服务器并连接。
2. 从账户菜单或现有任务的“更多”进入“Codex 任务”。服务器需要已有可用的 Codex 命令及登录配置。
3. 点击“新任务”，填写服务器上的项目绝对目录。已经有对话编号时，可用“恢复任务”接回原对话。
4. 输入要求，点击“加入队列”或按 Ctrl+Enter。默认手动派发；勾选“自动逐轮发送”后，在上一轮确认结束时发送下一条。

这条任务通道与现有终端任务并存。它使用所选服务器的运行器；本机保存任务登记、排队指令和服务器配置。未入队的文字及附件草稿只在当前应用进程保留，退出时会提示。

## 先体验这些操作

| 想做什么 | 入口与行为 |
| --- | --- |
| 找回任务 | 按名称或项目路径搜索，支持本机显示名、置顶、归档和恢复；归档不停止服务器工作 |
| 补充要求 | 输入后入队；运行中可明确选择“用下一条引导”，把队首要求交给当前轮次 |
| 查看执行 | 展开命令或文件改动卡片，查看输出、退出码或差异 |
| 处理审批 | 查看对应操作，单次允许或拒绝；其他问题可选答案或输入文字 |
| 查看文件 | “项目文件”浏览目录，点击进入右侧；也可输入路径或点击对话中的文件链接 |
| 编辑 Markdown | 在右侧切换源码/预览，保存到服务器；远端同时修改时提示比较处理 |
| 指导网页修改 | “网页预览”填写项目地址，使用已有刷新、选择元素、样式试调和反馈功能；反馈先进入本任务草稿 |
| 发截图 | “添加图片”、粘贴按钮或 Ctrl+V；上传完成后入队，支持 PNG/JPEG/WebP |
| 用语音或旧提示词 | 输入区“语音输入”“历史提示词”，内容先进入草稿，不自动发送 |
| 切模型 | 输入区读取服务器模型目录，选择模型和支持的思考强度，用于之后发送的轮次 |
| 换第三方线路 | 进入“线路设置”；当前运行器进程的线路热切换尚未完成，不将配置保存等同于当前任务已切换 |

## 遇到状态不明时

- “本地待发送”表示尚未提交运行器；“状态待确认”表示没有可靠接收结果，不要通过重复发送猜测是否成功。
- 断线后重新连接任务，查看恢复的历史及轮次状态。关闭应用会断开运行器连接，不能保证当前轮次继续执行。
- 图片上传失败可重试或移除。已经入队的附件路径随指令保留；服务器文件若被外部清除，需要重新上传。
- 模型选择“沿用任务当前模型”表示不覆盖运行器选择，不是恢复服务器最初的默认模型。
- 复制任务编号便于恢复同一服务器上的对话；它不是跨服务器迁移工具。
