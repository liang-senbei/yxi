# Windows 1.4.4 候选范围

状态：协作消息批次集中检查中，尚未启动正式构建或发布。官网版本仍为 1.4.3。

本批包含用户向组内成员发消息、用户回复 Agent 原消息、请求原接收 Agent 回复，以及投递记录查询和人工核对。消息卡片默认展示，历史日志仍可切换。

服务端通过 user-say/user-reply 区分用户与 Agent 身份，验证组成员及原任务实例，保留稳定消息 ID 和回复关联，复用暂停、预算和去重规则。桌面以独立 hub-user 记录保存投递状态，不混入普通任务提示词。

配套 yxi-hub 需升级，旧服务器脚本不会支持新通道。服务端隔离检查与桌面接线编译由 hk13 Agent 执行；生产服务器未改、未发送真实协作消息。正式发布前收齐检查结果。

尚未包含自动协作调度、自动处理完成回执，以及 Agent 向用户回信的专用通道；完整 PRD W05 继续执行。本批提供用户可操作的发送与回复，不替代剩余协作需求。

使用说明：[协作消息操作](windows-collaboration-messages.md)。

构建准备已委派 cc-yxi：冻结 32a4128，目标分支 codex/windows-release-1.4.4，尚未取得运行编号。用户发送UI静态接线和编译通过（ef95d30）；最终回复入口与服务器回复边界检查仍进行中，发布前收齐。
