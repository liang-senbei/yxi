# 账号身份与插件人工核对

状态：下一批开发内容，尚未发布。官网当前为 1.4.2。

在“我的”页面，“账号与连接”分别显示 Yxi 账号登录、所选服务器的 SSH 身份和 Agent 提供方配置。

点击“查询 Codex 认证”或“查询 Claude 认证”，读取对应服务器运行器报告的状态。查询不发送模型请求，因此认证已配置不等于线路可用。Claude 查询对应 SSH 用户环境，具体任务的独立环境可能不同。界面不展示邮箱、令牌或密钥；查询失败时可检查连接和运行器版本后重试。

账号资料请求被服务器拒绝时，先尝试续期一次。续期后仍被拒绝才要求重新登录；普通网络故障保留登录状态。

插件操作长时间处于“待确认”时，先查询结果并刷新服务器插件列表，确认实际安装、版本、启用状态以及没有仍在运行的操作，再在操作记录中选择“人工核对…”。确认后保留原记录，并允许后续操作；它不重试原操作，也不把未知结果认定为安装成功。

服务端会在操作锁下记录人工核对结果，未找到旧回执时也保留该操作编号，防止迟到的原请求重新执行。客户端遇到后续查询失败，不会把“人工已核对”降回“待确认”。

插件恢复的隔离检查已通过；认证查询与续期处理的定向检查进行中。真实 Windows UI 体验按 windows-manual-verification.md 验收。
