# 2026-09-20 用户体验修正

用户纠正优先于旧版按目录分类和动态背景设计。

1. 导航使用手机共用的服务器 ~/.yxi/groups.json：服务器 → boomassets/yunxi 等分组 → Agent。没有分组的会话放入未分组。保留组规编辑、组内新建、路径复制。手机修改后桌面刷新同步，多组成员可出现在多个组中。
2. 去掉聊天背景和输入框的移动光团、颜色循环；状态只切换固定淡色。重连圆点也停止闪烁。
3. 用户气泡悬停显示铅笔。分别提供载入草稿编辑与打开 Claude 原生回退选择器；后者仍需用户选择准确消息和恢复范围，不能宣称已实现按气泡精确回退。投递不明记录默认收成小入口，真实队列状态不伪造成功。
4. 模型/思考 chip 通过 M-p 打开 Claude 原生模型/强度选择器并切到终端，保留原生输入；“线路”chip和配置页直接进入第三方线路管理。线路表单增加 Haiku/Sonnet/Opus 模型映射，不必手改 settings.json。当前不是独立仿制的桌面模型选择器，运行器不支持的强度不伪造选项。

投递体验追加：服务器明确文字和回车写入时记为 Sent，不再无差别要求人工核对；旧 Unknown 只在回读到原服务器 terminal 记录后转 Sent。真正缺少回执的投递仍保留未知状态，不能重复发送来猜结果。Sent只表明投递，不代表Agent已处理。

Claude官方说明：双Esc在原生输入为空时打开回退菜单；Restore conversation恢复原消息到输入框，Restore code另有文件恢复语义；中途加入一轮的消息不一定有独立检查点。https://code.claude.com/docs/en/checkpointing
