# OpenCode 原生会话适配

2026-09-23。根据 https://opencode.ai/docs/server/ 核对原生 HTTP 接口；保持 Yxi 的本地/服务器工作台设计。

已新增 OpenCodeClient：供应商、历史、状态、消息读取，以及创建、异步发送、停止。所有请求携带工作目录，绑定本机 loopback；远端通过独立 SSH 转发访问。使用服务端 Basic Auth，不跟随重定向、不对写请求做应用层自动重试，响应限制 8 MiB。connected 只表示供应商连接，不能证明订阅权益或真实推理成功。

后续必须完成：自有 serve 进程及凭据生命周期、动态端口与 SSH 转发归属、原生版本/OpenAPI 核对、持久化创建和投递结果、事件及审批/提问、模型选择、新建与对话界面。真实运行器在隔离目录验证通过后才开放创建。现有 HTTP fixture 不代表原生运行器或用户订阅验收。

服务器 Session.agent 的二元推断不能扩展为把另外四种继续当 Claude；在连接新增会话入口时必须一并补齐会话身份和能力路由。
