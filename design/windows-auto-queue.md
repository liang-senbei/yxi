# 自动接续与调整方向

用户要求：工作中发出的消息默认排队，本轮结束后自动接上；每条可点击调整方向，无需再点发送。

开发实现：终端队列由App层调度，切换任务、打开设置不停止。只发送原主机和原运行实例的队首Local消息；审批、正在工作、断线或前序投递未知时等待。投递成功后观察忙转空闲或服务器轮次结束事件，再发送下一条，避免连续塞入多个回合。

Claude调整方向会将选中本地消息提到队首，请求一次Escape停止当前轮次，等输入可用再投递。Codex使用原生turn/steer，指向明确活动轮次。待审批时禁用调整方向，不代替用户批准。

Codex新建/打开/恢复对话默认开启自动逐轮发送；线路重连仍暂停。自动队列只在客户端运行且服务器连接时工作，退出后本地指令保留，未知投递不重放。

目前为开发分支，未发布。检查交hk13 Agent：编译、队首顺序与去重、未知阻塞、跨任务/主机隔离及方向调整。真实会话使用由用户验收，不操作生产Agent试发。
