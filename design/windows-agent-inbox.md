# Agent 回信收件功能

状态：桌面收件功能已包含在官网1.4.7；hk13配套reply-user脚本已升级为该冻结版本。其他服务器需要通过协作服务入口导出并安装配套脚本。

在协作记录中选择“回给用户”，查看 Agent 回信。默认只显示当前组；可切换到服务器全部组。没有分组信息的旧事件可在全部组中查看。

点击“查看原消息与回复”会退出收件筛选，以便同时显示原用户消息和关联回复。回信已保存不表示用户已读，也不自动确认原任务完成。

记录页默认每 10 秒刷新，可关闭。刷新保留已有消息；编辑消息或关闭记录页时停止轮询。仍可手动刷新。

配套服务端命令为 `yxi-hub reply-user <原用户消息UUID> <正文> [稳定新UUID]`，核对原接收 Agent 实例，保留用户身份与回复关联，不向虚构用户终端写入。核心隔离检查结果见windows-1.4.5-release.md；并发与故障时序等未测范围仍保留，不声称全量验证。此次升级未发送生产消息。

本批不包含自动协作调度和模型任务的完成判定。手动验收重点：筛选数量与组一致、关联跳转保留原消息、窗口关闭后停止刷新、用户回复能够回到原 Agent 实例。
