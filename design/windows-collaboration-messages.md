# 协作消息操作说明

状态：用户发送、用户回复和请求 Agent 回复已随 Windows 1.4.4 发布。hk13 配套 yxi-hub 已升级；其他服务器需要通过协作服务安装入口升级，旧脚本不支持用户发送通道。

在协作组成员页点击“发消息”，以用户身份向所选成员投递。界面显示服务器、组名和项目目录；消息记录保留编号。服务器再次检查成员和任务实例，任务重建后不投递到同名新任务。

协作记录默认显示消息卡片。对 Agent 发出的消息，可点击“回复此 Agent”，回复保留原消息关联。另一入口“请接收 Agent 回复”会打开用户指令编辑框，确认后加入原接收任务的待发送队列；这一步不是回复完成。

用户消息与普通任务指令分开记录。发送成功只表示终端写入，Agent 是否处理需要查看目标任务。断线或回执不明时不自动重发；在本机指派记录中按编号查看投递记录，核对实际情况后可标记人工已核对。

用户消息遵守指定组的暂停、时间与消息预算。已登记但未确认的消息编号不会重新执行。协作服务升级通过现有导出和安装入口，安装前保留旧脚本备份；hk13 的旧脚本备份为 /root/.local/bin/yxi-hub.before-1.4.4。

开发中的下一批会增加 Agent 回给用户的收件视图和 reply-user 通道。收件视图已接入开发分支，服务端仍在实现与检查，尚未发布。

尚未完成：自动协作调度、自动完成回执，以及 Agent 对用户消息的专用回信通道。上述内容继续按主 PRD W05 实施，当前用户发送/回复不代表整个协作目标已完成。
