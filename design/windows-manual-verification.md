# Yxi Windows 手动验收清单

本清单供你在功能交付后自行验证，不需要现在执行。按你的要求，后续开发以功能实现为主，不再主动运行测试、交叉验证或专项检查。历史验证结果保留在 `windows-workbench-progress.md`，不反复重跑。

请使用最终交付的 Windows 包；之前的测试包可能不包含最新改动。问题反馈时尽量附上构建标识，而不只写界面版本号。

## 建议先验这几项

| 项目 | 怎么操作 | 预期结果 |
| --- | --- | --- |
| 安装与启动 | 安装/打开新包，再正常退出、重新打开 | 能进入工作台，窗口布局正常，旧配置仍在 |
| 主机保存 | 添加两台测试服务器，修改名称和端口，退出后重开 | 两台记录和修改仍在，不需要重新绑定 |
| 主机切换 | 两台服务器使用同名项目或会话，来回切换 | 消息、文件、终端、预览和插件始终属于选中的服务器 |
| 新对话 | 选择服务器、目录和运行器，启动新任务 | 在所选目录创建任务，运行器正确，不重复创建 |
| 基本对话 | 发消息、查看回复、切换任务，再返回 | 对话、任务状态和输入草稿保持正确 |
| 文件和网页 | 从任务打开 Markdown、源码及网页预览 | 能在右栏查看，编辑或刷新后显示对应内容 |

## 主机、密码与恢复

- 使用测试服务器分别尝试密码和私钥文件登录；密码错误、私钥不存在时，应清楚提示，不能假装已连接。
- 已保存的服务器在重启、断网、重新登录 Yxi 账号后仍应保留。是否自动重连应遵循设置，不应自动新建 Agent。
- 给服务器设置地区标签，核对侧栏、选择器和搜索结果；仅修改地区不应断开现有连接，导出再导入应保留标签。
- 升级旧版时，检查旧漫游目录中的服务器是否迁移成功；名称、ID、地址、端口和用户名应保持一致。
- Windows 密码应由当前 Windows 用户的系统保护保存。迁移失败或新旧记录冲突时，应保留原数据并提示处理。
- **仅在测试配置副本上**模拟主配置丢失，再从恢复入口选择副本：未选中或取消时不恢复；无法验证的副本不可选；恢复后核对服务器列表。
- 私钥文件属于外部文件管理范围。移动、删除私钥后，检查提示是否明确。

仍需重点关注：活动密文和备份都存在但无法读取、不同 Windows 用户、旧版本降级、长历史副本列表。

## 服务器导入 / 导出

- 从主机菜单导出 JSON：应包含服务器信息，不包含密码、私钥内容或私钥路径。
- 导入刚导出的文件：先出现预览，再确认保存；取消不改变列表。
- 同一地址、端口和用户名的重复项应跳过，原有认证信息不被覆盖。
- 标识冲突但地址不同的记录应作为新服务器处理，不替换原服务器。
- 新导入的服务器需要自行填写认证信息，不能套用另一台服务器的密码。
- 导入期间若原列表发生变化，应提示重新预览。无效文件不应导致原配置丢失。

## 对话、运行器、模型与排队指令

- 点击麦克风后确认识别服务器，开始录音、停止识别、编辑文字并加入草稿；不应自动发给Agent。当前需服务器安装 `yxi-asr`，不是桌面本机离线识别。
- 若服务器没有识别服务，可从语音窗口打开安装步骤并导出安装包，上传到Linux服务器后执行包内脚本。安装会下载较大的模型，不修改Agent钩子；系统依赖需先准备。
- 可选择麦克风并刷新设备列表；重开后应保留选择，拔掉所选设备时应提示重新选择，不能悄悄换用另一台设备。
- 连续录制多段，识别文字应追加而不是覆盖已编辑内容；失败后可以重试原录音或丢弃，关闭窗口后不再保留该录音。
- 检查麦克风权限关闭、录音太短、取消、120秒自动结束和连接中断时的提示；退出前应停止麦克风。服务器临时录音清理在断网情况下也需关注。

- 分别选择已支持的运行器，在包含空格/中文的项目路径中启动任务。
- 切换模型或第三方线路，核对生效范围、提示及实际使用结果；不要只依据下拉框文字判断。
- A 服务器的线路、密钥不能自动进入 B 服务器。
- 编辑、重排、取消排队提示词，检查主输入框草稿是否保留。
- 点击输入框旁的历史图标，搜索本任务之前保存的提示词；追加后原草稿应保留，不自动发送，历史附件需重新添加。
- 输入历史支持展开全文和替换草稿；已有文字时替换应先确认，取消应保留原草稿。
- 点击对话搜索图标，在当前已加载的消息、回复和工具记录中搜索并定位；分组工具记录应展开所在组。
- 缩窄对话栏时，模型和上下文信息应换行，发送按钮及输入工具仍应可用。
- 发送后断网或重启：结果不明确的指令应显示待确认，不能自动重复发送。
- 自动下一轮投递、运行器确认回执、协作模式等，以最终交付的功能说明为准；当前不能把所有排队条目都当作已有自动执行能力。

## 右侧文件与 Markdown

- 打开不同服务器上的同名文件，切任务后核对路径和内容。
- 检查 Markdown 渲染、源码视图、分栏、图片、长文档和中文。
- 点击“查找”或在文档内按 Ctrl+F，输入文字后使用上一个/下一个；应切到源码并选中对应文字，Enter 查找下一个、Shift+Enter 查找上一个，不能修改文件内容。
- 修改后切换任务再回来，未保存内容应保留。
- 在外部或 Agent 中同时改同一文件：应出现冲突处理，不能静默覆盖。
- 保存失败时编辑内容应保留；退出时应提示未保存内容。

## 网页实时预览

- 配置项目地址和开发服务，启动、查看日志、停止；重新打开后检查地址恢复。
- 修改网页源码，观察热更新。没有热更新能力的项目，检查手动刷新及最终交付的自动刷新行为。
- 切换自适应、桌面、平板和手机视口，检查响应式布局和缩放显示；这只切换页面尺寸，不等同完整手机浏览器、触摸或 User-Agent 模拟。
- 切换网页主题的系统/亮色/暗色，观察支持系统明暗偏好的页面；未实现主题样式的网站不一定发生变化。此开关不改Yxi自身主题或网页源码。
- 尺寸与主题位于“预览设置”中；收起设置后页面应获得更多空间，设置仍保留，“恢复默认”应回到自适应尺寸和系统主题。
- 点击页面查找，输入关键词，使用前后匹配及大小写开关；Enter/Shift+Enter应定位，关闭应清理查找高亮。
- 页面未就绪、端口被其他程序占用、服务退出时，状态不能误报成功。
- 选择元素，尝试字号、字体、颜色、间距、圆角和纯文字试调；检查撤销、重置。
- 临时试调应明确区别于源文件已保存。加入对话后，检查地址、元素和修改要求是否对应当前任务。
- 切服务器后检查预览不串台；复制截图时确认画面属于当前页面。

## 插件

- 在 A 主机安装测试插件，在 B 主机确认没有被误报为已安装。
- 检查目录搜索、安装范围和项目路径确认，取消操作不应安装。
- 依次尝试启用、停用、更新、卸载；核对实际结果与界面提示，其他插件配置应保留。
- 更新后核对版本，不能仅凭“命令成功”判断功能正常；在新会话中实际调用插件。
- 从操作历史查询旧操作，或选择恢复配置/插件包。后续配置已经变化时，不应直接覆盖。
- 卸载应保留持久数据，不自动清理未指定依赖。
- 断线、超时或重启后，待确认操作不能自动重复执行。

仍需重点关注：真实远程市场、不同作用范围、权限和依赖声明、精确升级目标版本、依赖原安装路径的插件、跨文件恢复中断。安装记录、运行器识别和插件功能可用是不同状态。

## 账号及其他能力

- 登录、取消登录、重新登录、退出账号，核对资料和权益展示。
- 验证信箱的阅读、领取、删除及工单的新建、回复、重开查看。需要真实提交的步骤，可先用测试账号。
- 对照安卓版逐项检查语音、发送历史、置顶、消息提醒等生产力功能。
- “三个月权益”“Laize 的具体运行器定义”“官方协作模式”的验收，需依据最终确认的产品规则，不能凭现有占位或名称判断完成。

## UI 与 Windows 体验

- 你最关心的美观性：整体留白、层级、字体、图标、配色、卡片和按钮是否统一；避免堆砌技术说明。
- 尝试窗口缩窄、最大化，以及 100% / 125% / 150% 缩放。检查裁切、遮挡、弹窗大小和滚动。
- 使用中文输入法，检查 Enter、Shift+Enter、复制粘贴、快捷键、拖拽附件。
- 检查亮色/暗色、右栏开合、预览和终端上方菜单是否被遮挡。
- 实际日常使用后，再决定是否需要性能或长时间运行专项，无需一开始穷举所有边界。
