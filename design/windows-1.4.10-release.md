# Windows 1.4.10 数据持久化修复

状态：准备中，尚未发布。由已发布1.4.9源码7e9bb18分出，仅包含用户数据目录修复与设置入口；不混入后续模拟器和Markdown开发改动。

Windows持久数据改存USERPROFILE/.yxi，脱离LOCALAPPDATA/Yxi的安装目录。启动时迁移旧服务器记录、受Windows用户级DPAPI保护的登录凭据、偏好及任务整理文件；不复制安装器、current或packages，不删除源文件。现有目标数据优先，迁移标记防止已退出登录的旧记录再次被导入。

设置常规页面显示实际目录，可打开或复制路径；迁移失败会提示并暂用旧目录。事务式迁移与中途失败重试修复尚待合入，不能以当前构建状态宣称完整解决。

既有用户首次跨到修复版前应保留安装目录中的用户数据副本，不先卸载旧版。已被旧安装流程删除且没有备份的数据不能靠迁移重建；备份中的刷新令牌也不保证永远有效。后续正常更新应保持.yxi文件与加密保护方式不变。

依据：Velopack Preserving Files & Settings https://docs.velopack.io/integrating/preserved-files 。安装根不是跨卸载数据保留位置；目录混用是已确认的设计问题，但个别用户过去丢失的具体安装路径尚未复现。
