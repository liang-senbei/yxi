# 头像菜单、我的与设置

用户新要求：参考分类清晰的桌面设置体验，将我的、设置、账号切换与退出集中到头像菜单；打开我的和设置后使用左侧分类、右侧内容。

本批实现：
- 头像菜单分账号、工作台、登录操作三个区域，显示昵称/会员/版本，提供我的、设置、服务器配置与插件、模型与线路、切换账号、退出登录。
- 设置从长弹窗改为独立双栏页，分类支持搜索，保留常规、主题、通知与输入历史原有真实设置。
- 我的页面独立双栏，分类进入个人资料、账号与连接、钱包订单、商城、兑换码、信箱与工单；回到应用保留原任务。
- 登录沿用系统浏览器 + PKCE。显式登录/切换账号使用prompt=login consent，要求重新认证并保留offline_access所需授权；不在客户端收集密码，不伪造多账号登录成功。

依据：Logto官方说明支持prompt=login consent绕过浏览器SSO并重新认证：https://docs.logto.io/end-user-flows/sign-out 。第三方社交平台的具体选账号页面由提供方决定，不承诺所有提供方都显示相同账号列表。

检查交hk13集中编译与只读接线核对；不替用户登录生产账号。待验收：头像菜单分组、分类切换、返回原任务、浏览器不同账号登录、取消授权、切换后账户数据隔离。尚未发布。

发布状态更新：本批已随Windows 1.4.7上线。使用入口为左下角头像→我的/设置/切换账号；设置返回保留原工作区。真实账号登录由用户操作验收。
