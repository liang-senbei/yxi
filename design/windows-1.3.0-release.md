## 发布顺序

1. 现有Windows流水线完成并产生发布包；确认包版本、源码与冻结记录一致。
2. 将产物放到服务器独立暂存目录，核对发布清单引用的文件与校验值。
3. 先放版本化nupkg和安装程序，最后原子替换更新清单，避免客户端看到未上传完的包。保留所有旧版本文件。
4. 回读公开更新清单和安装程序响应，记录最终上线时间。失败时恢复旧清单和安装程序，不删除新旧包。
