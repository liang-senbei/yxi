# 供应商配置对齐需求

用户明确要求参考CC Switch供应商管理与添加页面，沿用其可商用MIT代码/预设时保留许可。

已接开发分支：按服务器隔离的Claude/Codex供应商列表，搜索模板、完整页编辑、名称/备注、端点、密钥/token、默认模型、Haiku/Sonnet/Opus映射、思考强度和额外Claude JSON。预设来源声明与MIT文本已随桌面资源打包。

仍需实现，不能由现有输入框代替：官网链接元数据；Fable/Subagent映射与1M能力校验；通用配置的来源/覆盖关系；完整URL模式；User-Agent、Header、Body覆盖的真实代理链路；更多Agent类型的专用适配器。代理字段必须实际应用在转发请求上，未实现前不显示为可用。

模板为既有快照，可编辑，不意味着其中端点/模型今天可用。不得自动填写用户真实密钥或把示例供应商加入生产线路。保存后仍由用户选择目标服务器/范围应用。

本轮尚未发布，截图功能全量对齐未完成；hk13协助有限协议/代理差距盘点和编译，中枢负责UI和集成。
