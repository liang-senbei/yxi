# Windows 1.4.6 体验修正候选

状态：准备正式构建，尚未发布。官网仍为1.4.4；旧1.4.5候选已构建但因用户新反馈暂停发布，修正并入本版。

本版优先处理用户四项反馈：手机共用分组树（服务器→分组→Agent）、无持续波纹和呼吸闪烁、气泡铅笔编辑/原生回退入口、模型强度原生选择器与第三方线路模型映射。

正常终端投递有回执时记为Sent，不再逐条要求人工核对；旧未知项仅按原实例的服务端投递记录核实后转Sent。真正不明的记录保持未知，默认收为紧凑入口。

铅笔目前可把原文放回草稿，或发送双Esc打开Claude原生选择器；精确定位及恢复范围由用户在原生菜单选择，未实现按气泡UUID自动回退。模型/强度chip使用原生M-p并显示终端选择器，模型支持范围由运行器决定。

第三方线路表单可填写端点、密钥/令牌、模型、强度及Haiku/Sonnet/Opus映射。参考CC Switch交互，未复制其代码/资产；MIT许可说明见windows-feedback-20260920.md。

包含未发布1.4.5的Agent回信收件功能。编译由hk13 Agent集中执行，投递状态变更交定向检查；不在生产会话上测试回退或切模型。剩余手动验收另列，不宣称全部PRD完成。
